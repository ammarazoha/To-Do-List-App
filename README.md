# My To-Do List App

A simple, beginner-friendly task manager made with HTML, CSS and JavaScript.

## Features
- Add a task
- Mark a task as completed
- Delete a task
- Filter tasks: All, Active and Completed
- Clear all completed tasks
- Automatically save tasks in the browser using localStorage
- Responsive layout for mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add your tasks and manage your list.

No installation, database or backend is required.

## Note
Tasks are stored in the browser's local storage on the device and browser where the app is used. They are not synced between devices.
